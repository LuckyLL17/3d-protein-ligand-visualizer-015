# 3D 蛋白质结构与配体结合可视化平台

React + Vite + TypeScript + React Three Fiber 的结构生物学可视化基础项目，用于展示蛋白质骨架、关键残基、配体原子和结合口袋关系。

## 当前能力

- 卡通带状、表面模型、原子视图三种互斥显示模式
- 模式切换保留当前残基与配体原子选择
- 表面模型支持不透明度调节和线框叠加
- 原子视图按主链键、配体键、残基原子、配体原子的层级渲染
- 不支持的标签和相互作用由界面状态明确说明
- 关键残基选择与空间定位
- 配体原子点击选择
- 配体旋转
- 关键残基、配体原子和相互作用图例
- 结合口袋指标卡片
- 残基角色、空间坐标、距离和作用类型展示

## 启动

```bash
npm install
npm run dev
```

当前使用内置示例结构数据，后续可接入 PDB/mmCIF 文件解析、真实原子键推断、分子对接结果、氢键几何筛选和结构比对。
