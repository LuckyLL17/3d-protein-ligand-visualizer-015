# 3D 蛋白质结构与配体结合可视化平台

React + Vite + TypeScript + React Three Fiber 的结构生物学可视化基础项目，用于展示蛋白质骨架、关键残基、配体原子和结合口袋关系。

## 当前能力

- 卡通带状模式：显示二级结构带、Cα 残基标记与残基标签
- 表面模式：显示连续半透明蛋白表面，支持透明度和线框叠加控制
- 原子视图：按“蛋白/残基/原子与键”和“配体/原子与键”的层级呈现
- 模式切换共享并保留当前残基和配体原子选择
- 表面模式不显示残基标签或非共价相互作用，并通过界面状态明确说明
- 任意时刻仅挂载一种蛋白表示，避免模式切换时短暂重叠两套模型
- 关键残基选择与空间定位
- 配体原子点击选择
- 配体旋转
- 关键残基、配体原子和相互作用图例
- 结合口袋指标卡片
- 残基角色、空间坐标、距离和作用类型展示

## 启动

```bash
npm install
npm run dev
```

当前使用内置示例结构数据，后续可接入 PDB/mmCIF 文件解析、真实原子键推断、分子对接结果、氢键几何筛选和结构比对。
